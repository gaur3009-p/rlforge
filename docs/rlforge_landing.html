[ The Problem ]

RL codebases are a mess.

Most implementations are either toy examples with no depth, or massive production systems impossible to learn from. Neither helps researchers move fast.

✗
Hyperparameters with no explanation
You see gae_lambda=0.95 but have no idea what it does or why 0.95.
✗
Algorithms that don't match papers
Undocumented tricks and differences from the original formulations that silently change behaviour.
✗
No separation of concerns
Buffer, network, training loop, and logging tangled into a single 600-line file.

[ How it works ]

Every line maps to a paper.

RLForge is structured so you can read the code alongside the original publications and understand exactly what's happening.

01
Collect a rollout

The agent interacts with the environment for rollout_steps transitions. All (s, a, r, done) tuples are stored in a typed RolloutBuffer on the target device.

02
Compute GAE advantages

Generalised Advantage Estimation (Schulman 2016) computes Ât via a backward pass over the rollout, balancing bias and variance with γ and λ.

03
Run mini-batch updates

For n_epochs, mini-batches are sampled and the clipped PPO objective, value loss, and entropy bonus are combined and back-propagated with gradient norm clipping.

[ Algorithms ]

The full research toolkit.

Each algorithm is a self-contained module with typed configs, documented hyperparameters, and paper citations.

PPO On-policy · Discrete & Continuous
Proximal Policy Optimisation

The dominant on-policy algorithm. Uses a clipped surrogate objective to keep policy updates stable. Implements GAE-λ, entropy bonus, value loss clipping, and orthogonal init.

L = E[min(rÂ, clip(r,1−ε,1+ε)Â)] − c₁LVF + c₂S[π]
DQN Off-policy · Discrete
Deep Q-Network + Double DQN

Mnih et al. 2015 with van Hasselt 2016 DDQN extension. Experience replay, target network, ε-greedy decay, Huber loss, and Xavier initialisation. Fully annotated.

y = r + γ·Qtarget(s', argmaxa Q(s',a)) [DDQN]
SAC Coming soon
Soft Actor-Critic

Maximum-entropy off-policy actor-critic for continuous action spaces. Automatic temperature tuning. Currently in development.

J(π) = E[∑ γt(rt + α·H(π(·|st)))]
TD3 Coming soon
Twin Delayed DDPG

Fujimoto et al. 2018. Addresses overestimation with dual critics, delayed actor updates, and target policy smoothing. Currently in development.

y = r + γ·mini=1,2 Qθᵢ(s', ã) where ã = π + clip(ε)

[ Get started ]

Running in three commands.

Clone, install, and train. No config files, no YAML, no ceremony.

1
Clone the repo
git clone https://github.com/yourname/rlforge && cd rlforge
2
Install dependencies
pip install -r requirements.txt
3
Train PPO on CartPole
python train.py --algo ppo --env CartPole-v1
4
Or use as a library
from rlforge.algorithms.ppo import PPO, PPOConfig
